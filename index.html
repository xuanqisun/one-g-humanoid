01 / TELEOPERATE

你的意图。
它的下一步。

按任务选择输入方式。三点遥操轻量上手，全身追踪传递更完整的动作。

ONE-G · 真机演示

三个追踪点，
一个完整的身体。

通过头部与双手传递上身意图，配合导航输入控制移动。支持手柄和手部追踪两种交互方式，无需脚踝追踪器。

输入
头显 + 手柄 / 手部追踪
效果
上身动作与移动协调控制

以 SONIC 为全身控制基础，呈现 ONE-G 的交互与部署演示。

02 / TRANSFER

身体不同。
能力可以相通。

适配已有策略，或训练跨本体共享模型。两条互补路线，让能力不止于一种机器人。

适配已有策略

Any2Any↗

运动学对齐，冻结策略主干，用 LoRA 适配动力学敏感模块，将已有控制能力迁移到目标机器人。

训练共享模型

MorphMimic↗

将形态信息输入共享世界模型与控制器，对齐跨机器人动作表示，让一套模型学习多种身体。

H2、X2 视频为 ONE-G 提供的演示，不作为 Any2Any 实验结果。H2 属于原 MorphMimic 论文验证本体之外的扩展演示。

03 / LEARN

更丰富的动作。
更可控的算力。

借助可微世界模型，探索在有限 GPU 预算下高效学习动作的技术路径。

SuperMimic

论文结果

1 GPU

3 小时 · NVIDIA H100

在作者基准中，超过已发布 SONIC checkpoint 的归一化回报。

MorphMimic

论文结果

3 GPUs

5 小时 26 分钟 · NVIDIA H100 NVL

训练覆盖 G1、X2 Ultra 与 T2 的统一模型，在不同本体间共享一套权重。

以上为原论文结果，并非 ONE-G 自测训练指标。两篇论文的硬件、数据与评估协议不同；SuperMimic 基准包含训练动作，衡量动作覆盖能力，不能据此直接横向排名。

核心思路

先学习运动规律。
再通过模型优化动作。

仿真采样→世界模型→策略更新循环迭代
