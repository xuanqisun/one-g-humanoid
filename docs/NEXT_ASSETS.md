# 下一版最有帮助的素材

目前素材足够形成完整第一版，下面的素材用于后续提升，不是发布前置条件。

1. **干净的首屏动作片**：横屏、固定相机、机器人全身与脚底完整入镜，10–20 秒，展示平衡、伸手或连续动作。尽量减少遮挡与背景杂物，保留原始无字幕视频。
2. **白底仿真渲染**：固定相机、白色地面与背景、柔和接触阴影，每个动作 6–12 秒、30/60 fps；提供机器人型号与对应动作/策略名称。可以用普通白底 MP4，不必强求透明通道。需要在非白背景使用时，可另导出含 alpha 的 WebM/ProRes 4444 或 PNG 序列。
3. **跨本体对比**：同一参考动作在 G1、H2、X2 等机器人上的同步渲染；一致机位、比例、速度；原片不加指标与文字，另提供可靠实验数据。
4. **三点 / 全身 / 双模式**：同一任务，操作者与机器人同框，分别展示设备、动作及输入切换。每段只突出一种能力。
5. **训练记录**：GPU 型号与数量、训练时长、数据量、策略版本、任务条件、失败次数，以及是否为 ONE-G 自测。只有可核对的数据才转为公司能力指标。

建议命名：`日期_本体_能力_真机或仿真_编号.mp4`。提供一份简短说明，写明画面中发生了什么、使用何种方法、哪些是部署结果，哪些仍是研发验证。
